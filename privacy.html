Política de privacidade do Atlas

Atualizada em 15 de outubro de 2026.

Atlas é um aplicativo de uso pessoal que roda apenas no computador do seu dono. Não existe servidor do Atlas: nenhum dado do Google é enviado para nós ou para terceiros por meio do Atlas.

Dados do Google acessados

  • Gmail: ler mensagens e criar rascunhos (o Atlas não envia e-mails).
  • Google Agenda: ler eventos e criar eventos aprovados pelo dono.

Como os dados são usados

Os dados são usados só para mostrar ao dono resumos do seu e-mail e agenda, preparar rascunhos e marcar eventos que ele aprovar. Trechos podem ser processados pelo modelo de IA escolhido pelo próprio dono, apenas para atender ao pedido feito por ele.

Armazenamento e compartilhamento

As credenciais de acesso ficam guardadas só no computador do dono. Os dados não são vendidos, não são usados para publicidade e não são compartilhados com terceiros.

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar

O acesso pode ser removido a qualquer momento em myaccount.google.com/permissions.

English summary. Atlas is a personal-use app that runs only on its owner's computer, with no Atlas server. It reads Gmail and Google Calendar, creates Gmail drafts (it never sends email) and creates events the owner approves. Data is used only to serve the owner's own requests. It is never sold, never used for ads and never shared with third parties. Atlas's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Revoke access at myaccount.google.com/permissions.
